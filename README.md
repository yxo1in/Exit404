## 게임 소개

Exit404는 선생님에게 잡히지 않고 학교를 탈출하는 게임입니다.

학교 곳곳의 책상에서 전공 문제를 풀면 열쇠를 얻습니다. **열쇠 10개를 모두 모아 출구로 가면 클리어**입니다. 선생님은 게임 내내 플레이어를 따라오고, 주변이 어두워 가까운 곳만 보입니다. 클리어하면 걸린 시간을 랭킹에 등록할 수 있습니다.

---

## 실행 방법

이 게임은 VS Code의 **Live Server**로 실행해야 합니다.

### 1. 프로젝트 내려받기

터미널에 아래 명령어를 입력합니다. 첫 줄은 프로젝트를 내 컴퓨터로 복사하고, 둘째 줄은 복사된 폴더로 이동합니다.

```bash
git clone https://github.com/yxo1in/Exit404.git
cd Exit404
```

### 2. Live Server로 실행하기

1. VS Code에서 `파일 > 폴더 열기`로 `Exit404` 폴더를 엽니다. 반드시 이 폴더 자체를 열어야 맵이 정상적으로 표시됩니다.
2. 확장 프로그램 탭에서 `Live Server`를 설치합니다.
3. `index.html`을 마우스 오른쪽 버튼으로 클릭하고 `Open with Live Server`를 선택합니다.
4. 브라우저가 열리지 않으면 주소창에 `http://127.0.0.1:5501/index.html`을 입력합니다.

### 3. 게임 시작하기

시작 화면에서 `START`를 선택합니다. 문제 창 크기가 고정되어 있으므로 브라우저를 **전체 화면(F11)** 으로 플레이하는 것을 추천합니다.

## 조작 키

### 게임 중

| 키 | 기능 | 사용 예시 |
| --- | --- | --- |
| `↑` | 위로 이동 | 복도에서 위쪽 방으로 들어갈 때 |
| `↓` | 아래로 이동 | 방에서 나와 아래쪽 복도로 갈 때 |
| `←` | 왼쪽으로 이동 | 뒤따라오는 선생님을 피해 왼쪽 복도로 돌아갈 때 |
| `→` | 오른쪽으로 이동 | 긴 복도를 따라 출구 쪽으로 갈 때 |
| 왼쪽 `Shift` + 방향키 | 달리기 | 선생님이 가까이 왔을 때 빠르게 도망칠 때 |
| `F` | 상호작용 | 책상 옆에서 눌러 문제를 열거나, 출구에서 눌러 탈출할 때 |
| `I` | 인벤토리 열기 | 지금까지 모은 열쇠를 확인할 때 |
| `Esc` | 인벤토리 닫기 | 열쇠를 확인한 뒤 게임으로 돌아갈 때 |

- 게임 중 이동은 **방향키로만** 할 수 있습니다. `W`, `A`, `S`, `D`로는 움직이지 않습니다.
- 대각선 이동은 없습니다. 방향키를 동시에 누르면 한 방향으로만 움직입니다.
- 달리기는 **왼쪽 Shift**로만 할 수 있습니다.
- 달리는 중에 아무 키나 떼면 달리기가 풀립니다. 방향을 바꾼 뒤 계속 달리려면 `Shift`를 다시 누르세요.

### 메뉴 화면

시작 화면, 게임 오버 화면, 게임 클리어 화면에서 사용합니다.

| 키 | 기능 | 사용 예시 |
| --- | --- | --- |
| `↑` 또는 `W` | 위 항목으로 이동 | 시작 화면에서 `RANKING`에 있는 화살표를 `START`로 옮길 때 |
| `↓` 또는 `S` | 아래 항목으로 이동 | 시작 화면에서 `START`에 있는 화살표를 `RANKING`으로 옮길 때 |
| `Enter` 또는 `Space` | 선택 | 화살표가 `START`에 있을 때 눌러 게임을 시작할 때 |
| `Esc` | 랭킹 창 닫기 | 순위를 확인한 뒤 시작 화면으로 돌아갈 때 |

한글 입력 상태에서는 `W`, `S`가 동작하지 않을 수 있습니다. 이때는 방향키를 사용하세요.

### 마우스

| 위치 | 동작 | 사용 예시 |
| --- | --- | --- |
| 시작 화면 메뉴 | 올리기, 클릭 | `RANKING`을 클릭해 랭킹 창을 열 때 |
| 랭킹 창의 `닫기 (ESC)` | 클릭 | 키보드 대신 마우스로 창을 닫을 때 |
| 문제 창의 입력칸 | 클릭 후 입력 | 정답을 입력하기 전에 입력칸을 선택할 때 |
| 문제 창의 `제출` | 클릭 | 입력한 정답을 채점받을 때 (`Enter`로는 제출되지 않습니다) |
| 인벤토리의 열쇠 | 클릭 | 오른쪽 설명 영역에서 열쇠 정보를 볼 때 |

게임 오버 화면과 게임 클리어 화면의 메뉴는 **키보드로만** 선택할 수 있습니다.

## 화면 구성

### 시작 화면

| 메뉴 | 설명 |
| --- | --- |
| `START` | 게임을 시작합니다. |
| `RANKING` | 기록이 빠른 순서로 상위 10명의 순위, 이름, 기록(초)을 보여줍니다. |
| `LANGUAGE` | 문제의 언어를 고르는 목록을 엽니다. 현재는 JavaScript만 있으며 처음부터 선택되어 있어서, 바로 `START`를 눌러도 됩니다. |

메뉴 양옆의 **화살표**는 현재 선택된 항목을 가리킵니다.

### 게임 화면

| 요소 | 위치 | 설명 |
| --- | --- | --- |
| 플레이어 | 화면 정중앙 | 내 캐릭터입니다. 플레이어는 항상 가운데에 있고 맵이 움직입니다. |
| 선생님 | 맵 안 | 플레이어를 끝까지 쫓아오는 적입니다. 벽을 피해 가장 짧은 길로 움직입니다. |
| 어두운 시야 | 화면 전체 | 플레이어 주변만 밝고 멀어질수록 어두워집니다. 어둠 속의 선생님은 잘 보이지 않습니다. |
| 나무 바닥 | 맵 안 | 교실입니다. |
| 타일 바닥 | 맵 안 | 교실을 잇는 복도입니다. |
| 갈색 영역 | 맵 안 | 벽입니다. 지나갈 수 없습니다. |
| 책상 | 교실 안 | 문제를 푸는 곳입니다. 맵에 총 10개가 있으며, 정답을 맞히면 사라집니다. |
| 초록색 빛 | 오른쪽 위 방의 오른쪽 벽 | 탈출 출구입니다. |
| 스태미나 바 | 왼쪽 아래 | 달릴 수 있는 힘을 나타내는 흰색 게이지입니다. |
| 타이머 | 오른쪽 아래 | 게임을 시작한 뒤 지난 시간을 `분:초`로 보여줍니다. |
| 알림 메시지 | 화면 위쪽 가운데 | `아이템이 지급되었습니다.`, `아이템이 부족합니다` 같은 안내가 잠시 나타납니다. |

**스태미나 바 사용법**

- 달리면 줄어들고, 걷거나 멈춰 있으면 다시 찹니다.
- 가득 찬 상태에서 약 3초 동안 달릴 수 있습니다.
- 게이지를 전부 쓰면 20%까지 회복될 때까지 달릴 수 없습니다.

### 문제 창

책상 옆에서 `F`를 누르면 코드 편집기처럼 생긴 창이 열립니다.

| 요소 | 설명 |
| --- | --- |
| 위쪽 메뉴, 왼쪽 파일 목록 | 편집기 분위기를 내는 장식입니다. 눌러도 동작하지 않습니다. |
| `Q.` 뒤의 글 | 풀어야 할 문제입니다. |
| `정답을 입력하세요` 칸 | 정답을 입력하는 곳입니다. |
| `제출` 버튼 | 입력한 정답을 채점합니다. |
| 아래쪽 터미널 영역 | 채점 결과가 표시됩니다. 맞으면 초록색 `Pass`, 틀리면 빨간색 `Error answer : 정답`이 나타납니다. |

### 인벤토리

`I`를 누르면 열리고 `Esc`를 누르면 닫힙니다.

| 요소 | 설명 |
| --- | --- |
| 왼쪽 `const INVENTORY` 영역 | 지금까지 모은 열쇠 목록입니다. |
| 오른쪽 `C:\Exit404\item >` 영역 | 클릭한 열쇠의 번호와 이름을 보여줍니다. |

### 게임 종료 화면

| 화면 | 언제 나오나요 | 선택지 |
| --- | --- | --- |
| `GAME OVER` | 선생님에게 잡혔을 때 | `YES`, `NO` |
| `YOU SURVIVED.` | 탈출에 성공했을 때 | `EXIT`, `RESTART` |

어떤 항목을 선택해도 게임이 초기화되고 시작 화면으로 돌아갑니다.

## 클리어 방법

**목표: 문제 10개를 맞혀 열쇠 10개를 모은 뒤, 출구에서 `F`를 누릅니다.**

### 1단계. 책상 찾기

게임은 왼쪽 위 방에서 시작하며, **선생님도 같은 방에서 출발**합니다. 먼저 방을 빠져나가 복도로 이동하세요. 책상은 다음 위치에 있습니다.

| 위치 | 책상 수 |
| --- | --- |
| 맵 위쪽에 나란히 있는 작은 방 3개 | 방마다 1개 |
| 맵 중앙의 작은 방 | 1개 |
| 오른쪽 위의 큰 방 | 1개 |
| 오른쪽 가운데의 방 2개 | 방마다 1개 |
| 왼쪽 아래의 큰 방 | 1개 |
| 맵 아래쪽의 방 2개 | 방마다 1개 |

### 2단계. 문제 풀기

1. 책상 바로 옆에 서서 `F`를 누릅니다.
2. 입력칸을 마우스로 클릭하고 정답을 입력합니다. 영어 대소문자와 앞뒤 공백은 구분하지 않습니다.
3. `제출` 버튼을 클릭합니다.
4. 결과가 나오고 2초 뒤 창이 자동으로 닫힙니다.

| 결과 | 일어나는 일 |
| --- | --- |
| 정답 | 열쇠 1개를 얻고 그 책상이 사라집니다. |
| 오답 | 정답을 알려주고, **선생님이 영구적으로 빨라집니다.** 책상은 남아 있어 다시 도전할 수 있습니다. |

문제는 아직 맞히지 않은 문제 중에서 무작위로 나옵니다. 틀렸을 때 본 정답을 기억해 두면 같은 문제가 다시 나왔을 때 맞힐 수 있습니다.

### 3단계. 선생님 피하기

- 선생님은 처음에 플레이어가 걷는 속도의 4분의 1로 움직입니다.
- 오답 1개마다 빨라져서, **6번 틀리면 걷는 속도와 같아지고 10번 틀리면 달리는 속도와 같아집니다.** 문제를 신중하게 푸세요.
- 문제 창이나 인벤토리가 열려 있는 동안에는 선생님이 멈춥니다. 다만 플레이어도 움직일 수 없고 타이머는 계속 흘러갑니다.

### 4단계. 출구로 탈출하기

1. `I`를 눌러 열쇠가 10개인지 확인합니다.
2. 왼쪽 위 시작 방에서 위쪽 복도를 따라 오른쪽으로 끝까지 갑니다.
3. 오른쪽 위의 큰 방으로 들어간 뒤, 방 아래쪽의 좁은 통로를 지나 맨 오른쪽 방으로 이동합니다.
4. 방의 오른쪽 벽에 있는 **초록색 빛** 쪽으로 갑니다. 오른쪽 벽에 붙어서 빛의 중심보다 살짝 위쪽에 서면 됩니다.
5. `F`를 누릅니다.

열쇠가 10개면 `YOU SURVIVED.` 화면이 나오며 클리어입니다. 열쇠가 부족하면 `아이템이 부족합니다`라는 메시지가 나옵니다.

### 5단계. 랭킹에 기록 등록하기

클리어하면 걸린 시간과 함께 이름을 입력하는 창이 나타납니다.

1. 랭킹에 표시할 이름을 입력하고 `확인`을 누릅니다.
2. 등록이 완료되었다는 안내가 나오면 `확인`을 누릅니다.
3. 시작 화면의 `RANKING`에서 순위를 확인합니다. 상위 10명만 표시됩니다.

이름을 비워 두거나 `취소`를 누르면 기록은 저장되지 않습니다.

---

## 게임 오버

선생님이 플레이어와 같은 칸에 도달하면 `GAME OVER` 화면이 나옵니다. 모은 열쇠는 모두 사라지고 기록도 랭킹에 등록되지 않으며, 시작 화면에서 처음부터 다시 플레이합니다.
